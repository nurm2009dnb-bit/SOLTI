# SOLTI 2.2.1

Настольная программа для студентов и разработчиков (Windows, Python): держит папку «Загрузки»
в порядке, засекает время учёбы, показывает, какими программами вы реально пользуетесь,
хранит списки аниме / манги / книг / фильмов и пароли — всё в одном окне.

Это отдельная версия в своей папке: код предыдущей версии в корне репозитория и данные старых версий не трогаются.
Данные этой версии лежат в `%APPDATA%\SOLTI_2.2.1\solti.db`.

## Разделы (кнопки на панели слева)
| Раздел | Что делает |
|---|---|
| **Сортировка файлов** | Раскладывает папку (по умолчанию «Загрузки») по правилам и таблице расширений. Предпросмотр, слежение в реальном времени, отмена. Если в папке уже есть файл с таким именем, к новому добавляется дата перемещения: `отчёт (14.11.2026).pdf`. |
| **Трекер приложений** | Считает время активного окна только для выбранных программ. Графики и итоги за сегодня / 7 / 30 дней. Время простоя не считается. |
| **Пароли** | Зашифрованное хранилище с мастер-паролем (Scrypt + Fernet), автоблокировка, очистка буфера обмена. |
| **Списки** | Аниме, манга, книги и фильмы: статус, прогресс, оценка, заметки, поиск и фильтры. |
| **Таймер** | Секундомер учёбы с целью, категориями, историей и итогами. |

Внизу панели — переключатель светлой / тёмной темы (выбор запоминается) и кнопка «Выход».

## Установка и запуск
```
cd SOLTI_2.2.1
python -m venv venv
pip install -r requirements.txt
python main.py
```

## Что нужно скачать для запуска
```
pip install -r requirements-dev.txt
```

## Сборка SOLTI.exe и ярлык на рабочем столе
Из папки проекта, с включённым `venv` и установленным `requirements-dev.txt`:
```
pyinstaller --noconsole --onefile --name SOLTI --icon assets\solti.ico --collect-all customtkinter main.py
```
Результат — `dist\SOLTI.exe` (иконка-планета уже встроена в файл). Ярлык на рабочем столе (PowerShell):
```
$exe = (Resolve-Path dist\SOLTI.exe).Path
$lnk = (New-Object -ComObject WScript.Shell).CreateShortcut("$([Environment]::GetFolderPath('Desktop'))\SOLTI.lnk")
$lnk.TargetPath = $exe; $lnk.WorkingDirectory = Split-Path $exe; $lnk.IconLocation = "$exe,0"; $lnk.Save()
```
Первый запуск занимает около 10 секунд. Иконку `assets\solti.*` можно перерисовать командой `python -m solti.logo`.

## Структура
```
main.py                  точка входа
solti/
  config.py              название, версия, пути к данным
  logo.py                логотип-планета (рисуется кодом)
  database/              таблицы, подключение, начальные правила
  services/              вся логика без интерфейса
  ui/                    главное окно с боковой панелью и разделы
assets/                  готовый логотип и иконка
```
